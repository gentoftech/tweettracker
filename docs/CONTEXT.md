## What this produces

A streamlined, **multi-workspace** X intelligence app built around **two primary action views** plus automated background maintenance:
1. **`Hot Posts` (`/radar`)** — An ephemeral live priority queue of climbing posts (`15–60m`) ranked by **`expected_reply_reach_score`** (blending breakout velocity, per-author empirical `yield_score`, projected post reach, and `20x` mutual lift), with plain-English **Reply** vs. **Quote** actions (recording `acted_action_kind`), per-author reply-yield badges (`~avg views/reply · +follows/30d`), hoverable **"Why it's hot"** tooltips, `Skip` / `Save` / `Undo`, and automatic drop-off once momentum fades.
2. **`Network` (`/network`)** — Self-organizing force-directed WebGL network map colored automatically by interaction clusters, paired with a unified **People** directory (`All`, `Top Movers`, `Follow Back`, `Rising`, sortable by `Reply Yield`), pure 1-step `+ Add People` (`@Handles`, `CSV Import`, `Sync X List`), explicit `Sync Network` + 6h worker sync, **Yield-Learned Core (`C_yield`) auto-adds** (zero follower-size cliffs, zero fixed caps), **unified hysteresis pruning (`< 0.32` after `48h` auto-add / `28d` seed bootstrap grace)**, and 1-click permanent **`Mute`**.
3. **`Settings` (`/settings`, gear icon)** — Encrypted **API Keys Vault**, workspace X Lists (`use_x_lists` + `x_list_ids_json`), **Monthly Unit Budget (`100k` units)** guardrail, plain-English **Model Accuracy & Automatic Tuning** (`Alert Hit Rate`, `Breakouts Caught`, `Early Head Start`, 1-click `Undo Last Tune`), `Gemini 3.8 Flash` / `Grok 4.7` model config, outbound webhooks, and automated `xai-org/x-algorithm` (`9106e9f`) sync. *(Legacy `/rising` redirects to `/network`; `/backtest` redirects to `/settings`. Own-post drafting remains deferred to Build 2.)*
